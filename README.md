## Projects

### Studio W&L — Booking System

*A full scheduling system for a real barbershop, replacing manual control by paper and WhatsApp.*

**Stack:** Java · Spring Boot · PostgreSQL · Docker

- REST API across 5 entities: appointments, clients, barbers, services, and subscription packages
- Automatic barber assignment when the client picks "any available," eliminating scheduling conflicts
- Admin panel with a timeline-based agenda and individual barber logins, giving the business real visibility into daily, monthly, and yearly revenue

---

### Personal Finance System

*An API for tracking expenses, categories, and financial goals.*

**Stack:** Java · Spring Boot · Spring Security · JWT · PostgreSQL · Docker · AWS

- Authentication with Spring Security and JWT
- Deployed to production on AWS (EC2, RDS, S3)
- CI/CD pipeline via GitHub Actions, API documented with Swagger

---

### Distribuidora — Transfer Management System

*A web system for managing transfers, with automatic professional PDF generation.*

**Stack:** Python · Flask · ReportLab · SQLite

- Authentication and PDF generation built with ReportLab
- Deployed to production on Railway
